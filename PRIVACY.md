# Политика конфиденциальности QuickSnap

**Дата вступления в силу:** 2026

QuickSnap разработан с приоритетом приватности пользователя:

1. **Никакого сбора данных и телеметрии.** Приложение не собирает персональные данные, статистику использования, логи сбоев или идентификаторы устройства и не передаёт их третьим лицам.
2. **100% локальная обработка.** Все скриншоты, аннотации и видеозаписи экрана создаются, обрабатываются и сохраняются исключительно локально в выбранной вами директории на Mac (по умолчанию — `~/Desktop/Screenshots`).
3. **Системные разрешения macOS:**
   - **Запись экрана (Screen Recording):** используется только в момент захвата области, окна или записи видео через Apple `ScreenCaptureKit`.
   - **Микрофон (Microphone):** запрашивается и используется только при явном включении записи голоса во время захвата видео.
   - **Доступ к файлам:** используется только для сохранения результатов в указанную папку и отображения недавних снимков в меню приложения.
4. **Отсутствие сетевых запросов.** Приложение не обращается к внешним серверам в фоновом режиме; переход по ссылке на GitHub выполняется только по явному клику пользователя.
