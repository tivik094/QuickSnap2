# QuickSnap 2.0

Нативная утилита для macOS в меню-баре для создания скриншотов с быстрой разметкой и записи видео с экрана со звуком.

## Установка из DMG
1. Откройте `QuickSnap_2.0.dmg` и перетащите **QuickSnap 2.0** в папку **Applications**.
2. Дважды кликните по скрипту **`Снять карантин.command`** внутри образа (сборка распространяется без платной подписи Apple Developer — скрипт снимет блокировку Gatekeeper и запустит приложение).
3. При первом скриншоте или записи видео включите переключатель для **QuickSnap 2.0** в **Системные настройки → Конфиденциальность и безопасность → Запись экрана** (и **Микрофон**, если нужна запись голоса).

> Для полной очистки приложения, конфигураций и сброса разрешений используйте скрипт **`Сбросить и удалить.command`** внутри DMG.

## Горячие клавиши по умолчанию
- `⌥ 1` — скриншот выделенной области
- `⌥ 2` — скриншот выбранного окна
- `⌥ 3` — запись видео с экрана

*(Хоткеи, директорию сохранения и параметры записи можно изменить в настройках из меню-бара.)*

## Сборка и релиз (для разработчиков)
- `./build.sh` — компиляция Swift-исходников и установка `QuickSnap 2.0.app` в `/Applications/`.
- `./build.sh --dmg` — полная пересборка приложения и упаковка готового образа `QuickSnap_2.0.dmg` на Рабочем столе.
