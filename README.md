# QuickSnap 2.2

Лёгкая нативная утилита для macOS для мгновенных скриншотов, аннотаций и записи экрана в MP4 с системным звуком и микрофоном на базе Apple ScreenCaptureKit.

## Основные возможности
- **Три режима захвата:** выбранная область (`⌥ 1`), окно приложения (`⌥ 2`) и запись видео экрана (`⌥ 3`) в 30/60 FPS со звуком приложений и микрофона.
- **Три темы оформления:**
  - **Нативный macOS** (по умолчанию) — матовый графитово-сапфировый интерфейс.
  - **Стекло (Glass)** — полупрозрачный эффект преломления с неоновой подсветкой иконок.
  - **Классика** — глубокий чёрный фон с контрастными акцентными кругами.
- **Недавние снимки:** прокручиваемая сетка до 18 превью с асинхронным даунсемплингом через ImageIO.
- **Редактор аннотаций:** стрелки, фигуры, маркер и быстрое копирование в буфер.
- **100% локально и приватно:** без телеметрии и сетевых запросов (см. [PRIVACY.md](PRIVACY.md) и [TERMS.md](TERMS.md)).

## Сборка
- `./build.sh` — сборка и запуск приложения
- `./release_dmg.sh` — сборка DMG-инсталлятора на Рабочий стол
