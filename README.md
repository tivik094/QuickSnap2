# QuickSnap 2.3

Лёгкая нативная утилита для macOS для мгновенных скриншотов, аннотаций и записи экрана в MP4 с системным звуком и микрофоном на базе Apple ScreenCaptureKit.

## Основные возможности

- **Три режима захвата:** выбранная область (`⌥ 1`), окно приложения (`⌥ 2`) и запись видео экрана (`⌥ 3`) в 30/60 FPS со звуком приложений и микрофона.
- **Индикация области записи:** некликабельная рамка по контуру записываемой области (не попадает в финальный MP4) и плавающая панель управления с индикатором уровня микрофона и паузой.
- **Три темы оформления:**
  - **Нативный macOS** (по умолчанию) — матовый графитово-сапфировый интерфейс.
  - **Стекло (Glass)** — полупрозрачный эффект преломления с неоновой подсветкой иконок.
  - **Классика** — глубокий чёрный фон с контрастными акцентными кругами.
- **Недавние снимки:** прокручиваемая сетка до 18 превью с асинхронным даунсемплингом через ImageIO.
- **Редактор аннотаций:** стрелки, фигуры, маркер и быстрое копирование в буфер.
- **100% локально и приватно:** без телеметрии и сетевых запросов (см. [PRIVACY.md](PRIVACY.md) и [TERMS.md](TERMS.md)).

## Структура проекта

- `Sources/App` — точка входа, делегат приложения, конфигурация и глобальные горячие клавиши.
- `Sources/Capture` — захват экрана, запись видео/аудио (`ScreenCaptureKit` + `AVAssetWriter`) и математика координат.
- `Sources/Editor` — окно редактора аннотаций и закреплённые поверх окон стикеры.
- `Sources/UI/Components` — переиспользуемые UI-контролы и токены тем.
- `Sources/UI/Windows` — поповер меню, окно настроек, панель предпросмотра, HUD и рамка записи.
- `Tests` — юнит-тесты координат, битрейта, таймингов и парсинга конфигурации.
- `Scripts` — скрипты сборки, тестирования и упаковки DMG.

## Сборка и тесты

- `./Scripts/build.sh` — прогон юнит-тестов, сборка и запуск приложения
- `./Scripts/release_dmg.sh` — сборка DMG-инсталлятора на Рабочий стол
- `./Scripts/test.sh` — запуск юнит-тестов
