# QuickSnap 2.0

Нативная утилита для macOS в меню-баре для создания скриншотов с быстрой разметкой и записи видео с экрана со звуком.

## Возможности
- Скриншоты выделенной области (`⌥ 1`) и окна (`⌥ 2`) с предпросмотром и аннотациями.
- Запись видео с экрана (`⌥ 3`) через `ScreenCaptureKit` (системный звук + микрофон).
- Гибкая настройка горячих клавиш, директории сохранения и параметров записи из меню-бара.

## Сборка и упаковка DMG
- `./build.sh` — компиляция Swift-исходников и установка `QuickSnap 2.0.app` в `/Applications/`.
- `./build.sh --dmg` — полная пересборка приложения и генерация готового образа `QuickSnap_2.0.dmg` на Рабочем столе (с инструкцией и утилитами снятия карантина/сброса).
